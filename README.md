# Cava Noble

E-commerce desarrollado en PHP y MySQL para la diplomatura inicial de PHP.

## Funcionalidades

- Registro e inicio de sesión de usuarios
- Catálogo de vinos
- Filtros mediante método GET
- Carrito de compras
- Checkout
- Panel administrador de productos
- Formulario de contacto
- Base de datos MySQL

## Tecnologías utilizadas

- PHP
- MySQL
- HTML5
- CSS3
- XAMPP
